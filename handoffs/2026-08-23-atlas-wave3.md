## What you asked → what exists

1. **Top bar / tabs.** 40 px bar; Live · History · Settings actually switch (the Home grid was overriding
   the `hidden` attribute); the tab lives in `location.hash` so reloads keep it.
2. **Atlas Engine.** Hand-rolled Canvas: core disc, thin ring, **96 radial bars** driven by 24 live
   frequency bands from the wake loop (`/signal`), state colours (ASLEEP grey breathing, LISTENING purple,
   THINKING rotating arcs + sweep, SPEAKING pulsing core), no glyph/letter/diamond. Draw cost measured
   live at **0.15 ms/frame** average. Research verdict: no permissive radial library accepts pushed bands
   (audioMotion is AGPL and needs Web Audio), so it is bespoke.
3. **History / Settings.** History lists terminal jobs with result fetch (paired bearer) and cancel on
   active ones; Settings shows voice/wake, **live audio devices**, MCP servers + tool counts, launcher
   availability, config paths.
4. **Overhead.** Worker **600 MB → 308 MB** idle, **13 s → 3.7 s** to `/state`: lazy Anthropic/ElevenLabs
   imports, only the configured wake model loaded, Deepgram Flux end-of-turn instead of LiveKit's extra
   local model. Audit with method + tables: `docs/audits/2026-08-23-overhead.md`. WebView2 (~400 MB across
   Chromium helpers) is the window itself and is unchanged.
5. **Bluetooth / device follow.** Mic and speaker now follow the Windows default device: the installed
   LiveKit supports reopening the mic in-process (`set_microphone_enabled(..., device=)`), the wake-word
   stream reopens on the new device at its native rate and resamples to 16 kHz (HFP-capable), TTS output
   already followed. Exit code 21 + in-place restart remains only for unresolvable devices. Live check:
   `/state.audio` = Intel mic array / "Headphones (AirPods)", both `following: true`.
6. **Workflow tests (spawned + monitored live, `docs` of each run in this session):**
   - quick reads: `count_mail` 2 unread (3.0 s), calendar (2.9 s) ✓
   - research job: real web searches, correct summary, 115 s ✓
   - CSV analysis: answered in-lane and correctly (total $105,675, best month June, 4.4 s) — after fixing
     OneDrive-redirected Documents via `known:` file roots ✓
   - Chrome job: background Claude Code with `claude-in-chrome`, real trending title ✓
   - confirm flow: Gmail draft created and verified by search — after making the host own the
     confirmation turn (an affirmative executes the pending action; a negative cancels; the model can no
     longer dodge `confirm` by re-proposing) ✓
   Defects found by these runs and fixed: taint blocked "peek then launch" (now launches with the
   host-substituted brief), Atlas narrated success over refused tools (prompt rules + honest narration),
   `open` used where a Chrome job was needed.
