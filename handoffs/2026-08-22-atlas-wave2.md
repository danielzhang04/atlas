## What changed

1. **Listening discipline (July gate reinstated).** `worker/addressing.py` + the silence clock in
   `worker/engagement.py`. After wake, speech is handled if it arrives within 30 s of Atlas's last
   activity, or contains "atlas", or hits the vocabulary (every app word from `config/apps.yaml` +
   `address_vocab` in `atlas.yaml`). Everything else lands in the transcript as `ambient` with no model
   call and no TTS. Two minutes without directed interaction → **silent** auto-sleep (mic muted, state
   ASLEEP, transcript `auto-sleep`, nothing spoken). "Go to sleep" / "that's all" still get the sleep line.
2. **Desk reach.** `find_file`, `open_file`, `read_file` over configured `file_roots`
   (`~/Desktop, ~/Documents, ~/Downloads, C:/Users/danie/kb`), and `close` (graceful `taskkill /IM`
   without `/F`, signed profiles only). Quick questions about a file are answered in-turn; real analysis
   goes to `launch_work`.
3. **Correct counts.** `count_mail` pages the Gmail MCP search (500/page, ≤ 4 pages) and returns an
   exact count. Live: "how many unread emails" → **2**; "how many emails total" → **60** (matches the raw
   MCP probe).
4. **The Atlas app.** `python -m worker.desktop` (or the Start-menu shortcut from
   `scripts/install_shortcut.ps1`) opens a native WebView2 window on the paired command center and runs
   the voice worker as its child. Close the window → Atlas is off (child tree terminated, port released).
   PM2 files are gone.
